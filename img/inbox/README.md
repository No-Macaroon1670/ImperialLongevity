# img/inbox — 收件箱

**照片丢这里。**整个目录不入版本库（见根目录 .gitignore），
所以里面可以是任何东西：没看过的、带人脸的、带 GPS 的、重复的、拍糊的。

处理流程走完之后，成品出现在 `img/own/`，这里的原件留着不动
——裁错了、认错了可以回来重做。

## 为什么要分两个目录

先前是按文件名模式挡（`PXL_*`、`*-orig.*`），挡不住两件事：
相机不叫这个名的（`20240104_140825.jpg` 就漏过了），
以及 agent 顺手写进来的中间产物（提亮图、局部裁切图，一次 7.5 MB 差点被推上 GitHub）。
**按目录挡才是干净的**：收件箱整个不入库，成品目录里的每一个文件都是过过手的。

## 一件事要你补

文件名里的 EXIF 拍摄日期能自动读出来，但**署名只写到月**
（「No-Macaroon1670 摄，2024 年 1 月」），日期精确到天没有意义，反而多给一层行踪。
EXIF 被剥掉的照片读不出日期，那种要你说一声是哪年哪月。
