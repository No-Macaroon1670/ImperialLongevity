# 勘合线 · 纪录片叙事稿

> 依据 `documentary-narrative` skill 流程产出：叙事契约 → 素材提炼 → 幕表 → 解说词。
> 形态：网页叙事长文（滚动阅读），每站解说词 200–300 字。
> 写完过一遍 `avoid-ai-writing`，记录见文末第五节。

---

## 一、叙事契约

**1. 观众通过谁的眼睛看**
不设人物主角。视点是当代的、站在展柜前的那个人——他手里唯一的工具是一块说明牌。
全篇第三人称，只叙事实与分歧，不下判断。

**2. 开头三分钟给出的问题**
一千年里，没有人指得出哪一件是秘色瓷。人们只有陆龟蒙一句诗，和几百年谁也说服不了谁的争论。
观众立刻会问：那后来是怎么知道的？

**3. 片子在追什么**
一个动作：**把东西和它的记录对上**。从规定标准，到刻标准，到写碑、铸商标、发凭证、建档案库，
到记录被烧、被伪造、被后人重排；最后回到那张封在地宫里的清单。
每一站都是一次勘合，成或不成。

**4. 结尾观众带走什么**
不是一条知识，是一个习惯：**下次站在展柜前，先看牌。**
以及一件不必安慰的事——记录是会被销毁的，而销毁记录的往往不是敌人。

## 二、幕表

**站序按年份走**（与石窟线、赤壁线同）：走线时视窗跟着站点移动，末站往回跳一千年会很怪。
天龙山系于 550，故落第五站，而它的文字跨到 1922 与 2020——器物的站位由自身年代定，
文字不受此限（库内 `石鼓` 简注写到 1936、`秘色瓷` 写到 2017，都是这个办法）。

| 幕 | 站 | 功能 | 出幕时读者手里的新问题 |
|---|---|---|---|
| 序 | 千峰翠色 | 悬置：名字活了一千年，东西一件指不出 | 那后来是怎么知道的？ |
| 1 立标准 | ① 石鼓 前575 | 最早的刻石文字，年代四说差四百年，连拓本都有假的 | 要对得上，先得有什么？ |
|  | ② 书同文 前221 | 标准是被规定出来的：文字、度量衡、车轨、钱 | 规定完了，怎么让抄的人不抄错？ |
|  | ③ 熹平石经 175 | 把校定本刻在石上，「拿来一对，便知正误」 | 石头能核对经文，还能核对什么？ |
| 2 记录的形状 | ④ 孝文帝汉化 494 | 元羽墓志：碑上那个姓，就是政令的回执；而死因只字不提 | 记录会漏掉什么？ |
| 3 转折（早置） | ⑤ 天龙山石窟 550 | 记录先于劫掠，一百年后又成追回的凭据；没有清单的还在原地 | 空白都是丢失吗？ |
| 4 记录的形状（续） | ⑥ 独孤信之死 557 | **呼吸点**：不是丢失，是写的人知道而不写。全线唯一一站没有实例、没有反转 | 官家会讳，那私人自己留的呢？ |
| 5 凭证 | ⑦ 开成石经 833 | 顾炎武据石补《仪礼》脱字；四库馆臣反核顾炎武 | 石头能校经文，那要认一件瓷器呢？ |
| | ⑧ 秘色瓷 874 | 清单与十三件瓷一一对应；而「秘色」二字出自窑场自己的匣钵 | 那皇帝自己的凭证靠什么算数？ |
|  | ⑨ 钱镠铁券 897 | 一式两份、用时勘合；而它自己的字数两说不一 | 官家的凭证尚且如此，民间呢？ |
|  | ⑩ 湖州镜 1114 | 私人商标，「真石家」三字说明有人仿冒 | 记录越留越多，留得下来吗？ |
| 6 失效 | ⑪ 郑和下西洋 1405 | 航海日志被下一任皇帝烧了 | 烧过之后，人怎么办？ |
|  | ⑫ 皇史宬 1534 | 石室金匮，防火防潮防虫防鼠；而它没有败给火 | —（接落点） |
| 落点 | 指得出 | 还清序的钩子；不总结 | — |

**悬念账本**

| 钩子 | 埋于 | 还于 |
|---|---|---|
| 秘色到底什么样 | 序 | ⑧ 给事实（十三件与帐文对上），落点给意义 |
| 石鼓年代四说 | ① | ⑪ 与宝船尺度并置：都因原始材料不存 |
| 碑漏掉了什么 | ④ | ⑤ 天龙山（漏掉的还在原地）；⑥ 独孤信（不是漏，是讳） |
| 凭证自己对不上 | ⑨ | ⑪⑫ 两站分还 |

**呼吸点：⑥ 独孤信之死。**原定 ⑦ 开成石经，理由是「无新论点，只给体量」——
但补入九站实例之后，⑦ 加了顾炎武补脱字与四库馆臣反核顾炎武两层，**变成全线最长最密的一站**，
呼吸点被自己填满了。改指定 ⑥：它是全线唯一一站没有实例、没有反转，讲的是碑的沉默，
位置又正在 ⑤ 天龙山那一记之后。**补内容会打坏节奏，这是本轮 documentary pass 查出的第一处。**

**过桥句**：每站首段是一句承接，把上一站末句留下的问题接过来。
用户 2026-08-19 定「Prefer coherence over brevity」，故各站字数放宽到 220–380，
不再压在 200–300——检验法是 documentary-narrative 那条：
**若前后几站对调而读者察觉不出，就是过渡没写。**

## 三、解说词

### 序 · 千峰翠色

唐人陆龟蒙写过一句诗：「九秋风露越窑开，夺得千峰翠色来。」他写的是秘色瓷。

宋代以后，这四个字变成了一个谜。它到底是什么釉色、哪个窑口、凭什么叫「秘」，
文献各说各的，学界与藏界争了几百年。有人指着一件青瓷说这就是，别人不服，也拿不出办法让他服。

问题不在于没有实物。问题在于：**没有任何东西能把一件瓷器和「秘色」这两个字绑在一起。**

一千年里，没有人指得出哪一件是。

### ① 石鼓 · 约前 575 · 陕西宝鸡

要把一件东西和一个名字绑住，先得有字。而中国现存最早的一批刻石文字，自己就绑不住。

十座花岗岩石墩，形如鼓，刻着中国现存最早的刻石文字。〔S1〕

它自己的年代却定不下来。韩愈、欧阳修主周宣王，罗振玉主秦文公，郭沫若主秦襄公，
唐兰考定为秦献公十一年（前 374），马衡只肯说「先秦」而不给具体年代——
诸说之间相差四百年。〔S1·各源不一致故不给年份〕

字也在减少。原有七百余，今存不足五百。十鼓之一「乍原」曾于 814 年失踪，
1052 年在一户屠家寻回时已被切去上半、充作磨刀石，字只剩四个。〔S1〕

它最有名的三种拓本也不可靠。先锋本、中权本、后劲本，1921 年为三井高坚购藏，
郭沫若据其照片写成《石鼓文研究》；2018 年经安思远旧藏元明间拓本比对，证明为伪作，
关键在「黄帛」二字间有无缺损。上海图书馆 2019 年的展览随即撤下所谓宋拓本。〔S1〕

**最早的一批字，自己没有年份，连它的影子也有假的。**这一千多年里，
人们要做的事从这里开始：不是把东西找出来，是把东西和一个说法对上。

### ② 书同文 · 前 221 · 咸阳

要对得上，先得有个准。石鼓之后三百多年，这个准被一道命令规定了下来。

秦并六国后，废关东六国原有文字，以自西周籀文演化的小篆为全国通用字体，
令李斯作《仓颉》七章、赵高作《爰历》六章、太史令胡毋敬作《博学》七章，作全国规范字帖。〔S2〕

同时做的还有统一度量衡、车同轨、行同伦。货币则废六国的珠玉、龟贝、银锡，
以黄金为上币、圆形方孔铜钱为下币，文曰「半两」。〔S2〕

两处常被说错：「半两」只是秦铜钱的统称，不指实际重量，《史记·平准书》说秦钱
「既重，又轻重不一」，并不好用；圆形方孔也不是秦始皇首创，《汉书·食货志下》
记秦钱「质如周钱」。〔S2〕

标准不是发现的，是**规定**的。规定完了，接下来的一千年都在处理一个问题：怎么让抄的人不抄错。

八百年后，这套字真的被拿去核过一次东西。隋开皇二年（582）五月，长安一个百姓从土里挖出一枚秦代铁秤砣，皇帝把它交给颜之推。他抄下砣上的四十个字，与内史令李德林一条条对——诏文里的丞相名字是「状」，爿旁作犬，他亲眼看清了；而当时通行的《史记》写作「隗林」。他判《史记》错了，本当作「隗状」。

他判对了。此后各地出土的秦权、秦量、秦诏版，写的都是「状」。可《史记》通行本至今仍印着「林」——**器物改正了记录，记录没有跟着改。**

### ③ 熹平石经 · 175–183 · 洛阳

「怎么让抄的人不抄错」，答案在四百年后落地，而且落成了一块石头。

东汉灵帝熹平四年动工，光和六年告成，立于洛阳城南太学门外，蔡邕、堂溪典、杨赐、
马日磾等书写。这是中国历史上最早的官定本儒家经书。〔S3〕

做法很朴素：朝廷把校定过的七经刻在石上，天下传抄的本子拿来一对，便知正误。〔S3〕

石经后来碎了。1929 年在河南洛阳故城大郊村发掘出残石，大部分 1952 年入藏西安碑林博物馆，
上海博物馆、中国国家博物馆、洛阳博物馆等也有零星收藏。〔S3〕

**一块可以让人拿去对的石头。**这是这条线上第一件为「勘合」而造的东西——
它存在的全部理由，就是被别人拿来核对。

碑立起来那年，来的是抄书的和看热闹的。真正拿它核书的人，一千年后才出现。南宋乾道年间，洪适把还认得出的一千五百多字，一个一个跟手边的刻本比，比出结果就记在正文底下——「板本作抑」「板本无而字」。他还算了账：石经《尚书》残存五百四十七字，以孔传本校之，石本多十字、少二十一字、不同者五十五字。

这是这条线上唯一一次，有人把「合了多少、不合多少」一笔一笔记下来。

### ④ 孝文帝汉化 · 494 · 洛阳

石头能用来核对经文，也能用来核对人。北魏孝文帝的一道政令，就落在一方碑上。

北魏孝文帝的汉化改革里有一条：改鲜卑姓氏与籍贯。这道令在一块石头上留下了回执。

1918 年河南洛阳出土的元羽墓志，北魏景明二年（501）刻，志文十三行一百七十七字，
首题「侍中司徒公广陵王墓志铭」。墓主元羽是孝文帝之弟、改革的支持者。〔S4〕
碑上他姓「元」不姓「拓跋」，籍贯写中原的「河南」郡而非代北——**改姓与改籍两项，
都由这方墓志自身的写法坐实。**〔S4〕

首题用的是追赠衔：元羽生前官居司空，卒后朝廷赠使持节、侍中、骠骑大将军、司徒公、
冀州刺史，谥惠。〔S4〕

而这方墓志不写的那一半更值得一提。《魏书》系统记元羽与员外郎冯俊兴之妻私通，
景明二年五月夜赴约途中被冯俊兴拦住殴打，十八日卒，虚岁三十二。〔S4〕

这一段，碑上只字不提。

太和十九年的诏书把核验程序写得一清二楚：先问宗族，再「勾其旧籍，审其官宦」，对上了才准奏，伪报者与经办者各有刑责，三月一造簿帐送门下。

**留下来的只有这段程序。**一个执行的案例都没有——倒是有个叫寇猛的代人冒认了上谷寇氏，而且冒认成功之后，当上了负责品评门第的燕州大中正。

### ⑤ 天龙山石窟 · 550 · 山西太原

记录会漏掉东西，也会救回东西——有时是同一批记录。

天龙山约始凿于北魏末至东魏，东西两峰崖壁延伸约五百米，现存造像五百余尊。〔S13〕

近代它是中国被凿得最惨的石窟群之一。而它被记录下来，比它被凿走更早。

1918 年日本建筑史学家关野贞考察，1921 年在《国华》发表，自此受国际收藏界注目。
1922 年田中俊逸系统调查、摄影、**编号**，同行者外村太治郎出版《天龙山石窟》图集，
**记下了造像被盗凿前的样子**。〔S13〕

二十年代遭大规模盗凿。日本古董商山中定次郎及山中商会为主要参与者，佛首、佛手自窟壁切割，
**有时佛身与佛首分开出售**。据近年调查逾二百四十件遭凿，至少一百五十余件流入境外数十家机构。〔S13〕

2020 年 9 月，国家文物局发现日本一家拍卖行拟拍一尊佛首。**经历史照片比对、石材检测
与造型研究**，确认属第八窟北壁主尊、约 1924 年前后被凿，遂停拍；旅日华侨张荣洽购后捐赠，
同年 12 月运抵北京。〔S13〕

**是同一批照片，先把它推到了买家眼前，又在一百年后成了要回来的凭据。**

而另有一部分造像因早期交易记录不完整，原属洞窟至今存争议。〔S13〕
**没有清单的那些，还在原地。**

### ⑥ 独孤信之死 · 557 · 咸阳

不是所有的空白都是丢失。有些是写的人知道，而不写。

1953 年陕西咸阳底张湾出土的独孤信墓志，志盖已佚，志文十六行二百二十字，
首题「周故柱国大将军雍州刺史河内戾公墓志」，只记姓名、籍贯、家世、卒葬，
以及夫人和三个儿子的名字。〔S5〕

写它的人有充分的材料可写。独孤信是北周明帝、隋文帝、唐世祖三人的岳父，
隋炀帝与唐高祖的外祖父；九个女儿里，长女为北周明敬皇后，七女独孤伽罗为隋文献皇后，
四女由唐追封元贞皇后。《周书》《北史》评此事自古未有。〔S5〕

碑上却只字不提。周孝闵帝元年，他与赵贵谋除权臣宇文护，事泄，被逼在家中自尽，
虚岁五十四，谥「戾」。〔S5〕**写这方碑的时候，他还是那个刚被赐死的戾公。**

隋文帝即位后追赠太师、上柱国、赵国公，改谥「景」；唐朝再追封梁王。〔S5〕
谥号往上改了两次，碑却只有一方。

### ⑦ 开成石经 · 833–837 · 长安

一方碑可以省略一个人的一生。而同一时期，另一种碑正在越立越多、越立越大。

唐文宗大和七年始刻，开成二年刻毕，艾居晦、陈玠等书。
《周易》《尚书》《毛诗》《周礼》《仪礼》《礼记》《春秋左氏传》《公羊传》《穀梁传》
《孝经》《论语》《尔雅》十二种儒家经典，刻于一百一十四座碑石，立于长安国子监。〔S6〕

它是唐代所作的标准楷书。北宋年间数次迁置，最终安置于西安府学北墉——
**今天的西安碑林第一室，碑林正是由它聚起来的。**〔S6〕

与东汉熹平石经、曹魏正始石经（三体石经）并称中国古代三大石经。〔S6〕

五代后蜀又刻广政石经，始于广政元年，至南宋绍熙末年方毕，石碑一千多方、十三部经典，
并在经文下附注文，为历代石经所独有。〔S6·据国博展签〕

顾炎武在关中做的事很简单：拿石头核纸。他四次入关中，其中一次亲见石经原石，取拓本逐字校明代国子监刻的《十三经》。《仪礼·士昏礼》一句下面，石上刻着十四个字，监本一个都没有。他把这十四字抄回去，判词只有一句——「此则秦火之所未亡，而亡于监刻矣」。今天翻开通行本，那十四字又在了。

一百多年后，四库馆臣把同样的动作对着顾炎武做了一遍：他引作唐石经的「子朝奔郊」四字，「字体与唐不类」，其实是明嘉靖地震后王尧惠等人补刻上去的小石。**核别人的人，也被核了。**

### ⑧ 秘色瓷 · 874 · 陕西扶风

石头能校经文。可要认一件瓷器，得等到另一样东西跟着它一起出土。

1987 年，考古工作者发掘陕西扶风法门寺塔基唐代地宫。地宫封闭于咸通十五年（874）。〔S7〕

出土文物中有十三件越窑青瓷。同封在地宫里的，还有一方碑刻——
《监送真身使随真身供养道具及恩赐金银衣物帐》。〔S7〕

帐上写着三个字：**瓷秘色**。〔S7〕

十三件瓷与帐文一一对应。争了几百年的事，就此有了标准器。〔S7〕

至于「秘色」何以得名，后世三说并存：宋周辉《清波杂志》谓臣民不得用故曰秘色；
一说烧制技术高度保密；另有学者认为是秘草的颜色。名字的来历至今没有定论。〔S7·三说并存，不择一〕

窑口却坐实了。1977 年上林湖出土唐光启三年凌倜墓志罐，志文点明该处有「贡窑」，
位置指向后司岙；2015 至 2017 年发掘后司岙窑址，器型与法门寺地宫所出一致，
2017 年更出一件瓷质匣钵，上书「罗湖师秘色椀」。〔S7〕

**「秘色」二字出自晚唐窑场自己的生产用具**——不是宋人事后追加的雅称。
一千年里没人指得出的那件东西，烧它的人自己一直这么叫。

### ⑨ 钱镠铁券 · 897 · 中国国家博物馆

地宫里那张帐是无意间留下的旁证——它本来是记账用的。而有一种东西，从造出来那天起就是为了对。

唐昭宗乾宁四年八月制，赐给后来的吴越国建立者钱镠。形如覆瓦，上嵌金字诏书，
写明钱镠本人可免九次死罪，子孙可免三次；若触犯国家其他法律，有关官员也不得过问。〔S8〕

铁券的做法从汉代就定下了。王佐《铁券考》记：「汉高帝平定天下，剖符封功臣，
申以丹书之信，重以白马之盟，始作铁券，其内镂字，以金涂之，故名曰金书铁券。」
而与功臣剖符作誓之后，是**「丹书、铁契、金匮、石室，藏於宗廟」**——
一半给人，一半存档，**用时两半合起来对**。〔S8〕

字数却对不上。中国国家博物馆藏品页称此券「上嵌金字诏书三百三十三字」，
而同页引《十国春秋》作「券文凡三百二十二字」。〔S8·同源两说，故不给数字〕

铁券是这条线上唯一一件生来就为对合而造的东西。可七百年里，没有一次两半合验留下记录。唯一一次货真价实的比对发生在开禧三年六月（1207）：八十三岁的陆游在钱氏后人手里见到一份铁券抄本，回家取出自藏的钱惟演旧字帖，把两处押字摆在一起看——「皆与此同」。

他核的是抄本，不是那块铁。铁券实物他只在十二三岁时见过一眼，记得它「状如筒瓦」。

### ⑩ 湖州镜 · 1114 · 浙江湖州

官家的凭证尚且如此。同一时期，民间正在自己想办法。

宋代湖州所铸铜镜，多作葵花形，素背无纹，只在背上铸一行铭记：
「湖州石家青铜照子」「湖州真石家念二叔照子」「湖州薛晋侯造」。〔S9〕

那是商标。标出产地与作坊，而铭文里那个「**真**」字说明当时已经有人仿冒。〔S9〕

两宋湖州有名有姓的私人镜坊有石、李、徐、丁、陆、黄、韩、蒋、冯、符、刘、万等家，
石家的号排到石十五郎，另有官营的湖州铸鉴局。〔S9〕

「照子」即镜，是宋镜特有的叫法，或因避宋太祖祖父赵敬的「敬」字讳。〔S9·或说〕

纹饰减省是为省工时——**镜子此时已从贵族整容的高档器变成平民日用的商品**，
远销朝鲜、日本。一件日用品开始自己说明自己是谁做的，这在这条线上是第一次。〔S9〕

镜背上刻着店名、地址，还有一个「真」字。可宋代没有一条记载，说有谁拿这个「真」字核过什么。**这一站只有记录，没有对上。**

### ⑪ 郑和下西洋 · 1405 · 南京

记录越留越多。但留得下来，是另一回事。

明成祖命郑和七下西洋，历时近三十年。第七次人数据祝允明《前闻记》为二万七千五百五十人。
宣德八年四月，郑和于返航途中在印度西海岸古里去世。〔S10〕

一手记录已不存。仁宗即位后以下西洋耗费庞大为由下令停航，
并**烧毁宫中郑和下西洋的日志与文件**。〔S10〕

于是宝船有多大，今天说不准。《明史》作长四十四丈四尺、广十八丈；
质疑派据南京静海寺残碑与出土舵杆估为长四十五至五十五米。〔S10·各源不一致故不给数字〕
而现存最早的尺度记载，出自罗懋登的演义小说《西洋记》，其余文献多转录自它。〔S10〕

记录失效还有第三种方式：由后人重排。「龙门二十品」的篇目不是北朝人所定，
而是清人康有为在《广艺舟双楫》中，自龙门数千方造像记里拈出的二十方。〔S11〕

留下来的是几块石头和几页抄本。郑和自己在刘家港刻过一碑，把七次出洋的年月一条条记上；碑早没了，碑文抄在一部明人的书里。把它摊在《明史》旁边对——第一次对上，第七次对上，中间五次全对不上。

2010 年 6 月，南京挖出一方墓志，志主是郑和的副使洪保，志立于宣德九年。他自述当年乘的是「五千料巨舶」。学界为宝船有多大争了几十年，1985 与 2004 两轮才勉强谈拢「二千料」——一句自述又把它顶翻。

### ⑫ 皇史宬 · 1534–1536 · 北京

烧过一次之后，有人开始盖房子。

明清皇家档案库，又称表章库，专藏实录、圣训、玉牒，明代曾在此存《永乐大典》副本。
嘉靖十三年动工，初名神御阁，十五年竣工敕赐今名。〔S12〕

造它的人把木头去尽。主殿为拱券式无梁建筑，墙身以特制磨砖砌成、厚五米，
额枋斗拱门窗皆汉白玉雕成，山墙南北对开窗以通气，兼防火、防潮、防虫蛀、防鼠咬。
殿内一点二米高的汉白玉须弥座上，置雕云龙纹镀金铜皮樟木柜一百五十二具。〔S12〕

这是史书所称「石室金匮」的典范——**跟汉高帝剖符封功臣时那八个字，是同一句话。**〔S8〕〔S12〕

1955 年后，皇史宬的归属权在国家档案局与故宫博物院之间数度往返。
南院渐迁入两家单位职工二十余户，做饭取暖使用明火，照明使用裸露电线。
两家单位都想争产权，都不愿先迁走居民，搬迁腾退因此无法进行。
2005 年北京市文物局下发《责令限期改正通知书》；2019 年底腾退方告完成。〔S12〕

它真正被当作副本用起来，是 1930 年 6 月：故宫博物院文献馆派人进去，逐函逐卷地点。1934 年出的那本总目，把乾清宫、皇史宬、内阁实录库、清史馆四处所存并排列成表，汉、满、蒙各列一栏，标明存佚卷数。**皇史宬缺在哪里，是这样才显形的**——缺口能报到函、报到卷，靠的正是同一部书抄了好几份。

**而它自己，没有败给火。**

  **最容易破在形容词上，不在结论句上**。

## 五、avoid-ai-writing 过稿记录

**先说这一节自己的一处错。**初版的这一节写成了「初稿 4 处，保留 2 处，删去另 2 处」
「初稿 6 处，保留 3 处」「共 5 处，全删」这样的账。**但本稿是一遍写成的，没有那个初稿。**
那些数字是编的——等于伪造了一份工作履历，让过稿记录看起来像真做过一轮删改。已全部改掉。

以下是**对终稿的实测**（脚本正则统计，非回忆）：

| 项 | 终稿实测 | 判断 |
|---|---|---|
| 「不是 X，是 Y」句式 | **2 处**：②「标准不是发现的，是规定的」；①「不是把东西找出来，是把东西和一个说法对上」 | 两处都是论点本身，非修辞装饰，保留 |
| 空心强调词（真正／其实／值得注意的是／的确／令人…） | **0** | — |
| 情绪与判断词（可惜／不舒服／讽刺／遗憾／难怪／不禁…） | **0** | 硬规矩⑤ 最易破在形容词上，故单列一项扫 |
| 三项并列 | **11 处**，其中 10 处是来源原文的列举（先锋本／中权本／后劲本；实录／圣训／玉牒；防火／防潮／防虫蛀／防鼠咬……）；自撰的只有序里「什么釉色、哪个窑口、凭什么叫『秘』」1 处 | 来源列举不算毛病；自撰 1 处保留 |

中文稿与 `avoid-ai-writing` 规则的关系：该 skill 的词表（Tier 1/2/3）与 em dash 频率针对英文行文，
不适用；可迁移的是三类结构性毛病——反复的「不是X是Y」、空心强调词、为凑排比而写的三项并列。
上表即针对这三类实测。

**未处理的一处**：⑦ 站「争了几百年的事，就此有了标准器」句式偏总结。保留，
因为这一站的功能就是给出序所埋问题的一半答案；此处不总结，悬念账对不上。

## 七、九站实例检索（2026-08-19）

用户问「这个 storyline 还可以加一些 coherency，需要 agent 多 research 一下吗」。
问题诊断：**这条线宣称「每一站都是一次勘合」，可初稿十二站里只有三站真的演示了那个动作**
（石鼓的「黄帛」二字辨伪、天龙山的历史照片比对、秘色瓷的帐物对应）。
其余九站只给了「这里有一份记录」，没给「有人拿它对上了什么」。**主题是宣称的，不是演示的。**

遂派九路检索，每路一站，问同一个问题：**有没有一次有据可查的实例——
某年某人实际拿这份记录去核对、验证、辨伪、追索？**
硬规矩随任务下达：绝不编造，查不到写「未能找到」；每条给可核验 URL 与原话；
分歧全列；**不许把「这份记录本来就为核对而造」当成实例**——那是设计意图。

七站找到，两站未找到。另派一名汇总者从严复判，剔除若干。

### 采用（六站，见 S14–S20）

书同文（颜之推 582）、熹平石经（洪适 1166–67）、开成石经（顾炎武／四库馆臣）、
钱镠铁券（陆游 1207）、郑和（碑文对《明史》＋洪保寿藏铭）、皇史宬（1930 点查／1934 总目）。

### 改写为反例（两站）

- **孝文帝汉化**：太和十九年诏把核验程序写得一清二楚，而一个执行案例都没有；
  倒有寇猛冒认上谷寇氏成功、并当上负责品评门第的燕州大中正。
  **制度设计得最像勘合的一站，恰恰一次也没演示过**——这比硬凑一个实例有力。
- **湖州镜**：明写「这一站只有记录，没有对上」。

### 驳回（记此以免重提）

**独孤信墓志订正《周书》一说被驳回。**于璐（2020）指墓志作「雍州刺史」而《周书》作
「秦州刺史」，判「当以墓志为是」。驳法：《周书》多处作秦州且有独立叙事支撑
（「信在秦州，尝因猎日暮，驰马入城，其帽微侧」的侧帽故事）；墓志首题依例记**卒时官衔**，
而其时他已因赵贵案坐免。**秦州与雍州完全可以是先后两任**，墓志所补是史书失载之末任，
不是史书之误。此说刊于美术类期刊，未见任何复核或商榷。

值得记一笔的是：同日我自己核过这方墓志的「雍州／襄州」之异（实物首行与展签双重核对，
判定作雍州），**却没想到要问「雍州和秦州能不能并存」**。
核对两个抄本之间的异文，与判断两条记载是否真的冲突，是两回事。

其余驳回条目见第六节「采而未用者」。

## 八、documentary 复盘（2026-08-20）

用户要求「用 documentary skill 再 pass 一遍」。按 skill 的三条硬检验逐项跑，
**查出三处结构问题，全部是我自己上一轮补实例时造成的**。

### 一、呼吸点被自己填满了

skill：「信息密度高的段落之后必须给一个呼吸点……否则观众会累到听不进去。」

原定 ⑦ 开成石经为呼吸点，理由是「无新论点，只给体量」。而补实例时我给它加了
顾炎武补脱字与四库馆臣反核顾炎武两层——**它变成全线最长最密的一站（430 字）**。
十二站于是每站都有实例、都有反转，一处松的都没有。

改指定 ⑥ 独孤信之死为呼吸点：全线唯一一站没有实例、没有反转，讲的是碑的沉默，
位置又正在 ⑤ 天龙山那一记之后。

### 二、两站的末句被实例段挤走了

skill 的幕表要求每幕写清「出幕时观众手里的新问题」，并称那一栏是「结构好坏的试金石」。
补实例时我把实例一律加在末尾，于是：

- **⑫ 皇史宬**：最强的收尾「它没有败给火」被推到实例段之前，全线倒数第二站改收在
  1934 年总目的技术描述上，**接不进落点**。已把实例段前置，末句归位并改为
  「而它自己，没有败给火」——承接落点的口气。
- **⑧ 秘色瓷**：全线答案的给出处，却收在「得名三说并存」的学术分歧列举上，泄气。
  已把三说上移，改收在「一千年里没人指得出的那件东西，烧它的人自己一直这么叫」。

### 三、两站的卡与长文互相复述

skill 第一原则：「解说词不描述画面里能看见的东西……如果它像一篇完整的说明文，
那它就是在复述画面，必须删。」在这条线上的对应物是：站卡的 `b2` 与长文不该互为摘要。

以 8 字重叠度实测十二站：郑和 **73%**、湖州镜 **64%** 明显过线——读了卡再读长文等于白读。
两张卡已重写为钩子而非摘要（郑和改讲「一切都建在替代品上」，湖州镜改讲「那个『真』字
同时说明有人在冒充它」）。复测后最高 52%（独孤信），全部 ≤55%。

### 未改的一处

② 书同文 414 字，位置在第二站，偏早偏重。保留：颜之推那条是全线最硬的实例之一
（第一人称亲历、年月人物器物下落俱全），而「器物改正了记录、记录没有跟着改」
这个反转正是全线的母题第一次出现，不宜后置。
