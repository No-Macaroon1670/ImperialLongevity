# 故事线解说词：常见错型清单

2026-08-20 对三条线（石窟、赤壁、勘合）做了一轮三镜头评审（AI 腔／纪录片纪律／
生硬拗口），45 条意见复核通过 23 条、全部落地。**此后起新线，写完先对照这张单子
自查一遍**——这些不是风格偏好，每一条都在自己线上真实出过。

## 一、事实层（最重）

1. **短文案与长文的事实级别必须一致。**
   窄屏读者只读得到卡片上的 b/b2，读不到长文里的限定语。长文写「学者推断、
   大体被接受」，卡片就不许写成断言。
   实例：云冈卡片「五尊大像，对应五位先帝」——长文自己写明那是二十世纪学者
   重建的推断。改：「学者推断对应五位先帝」。

2. **接力的事别安在一个人头上。**
   实例：「海通法师发愿开凿，凿了九十年才成」——海通死时佛未成，是三个人接力。

3. **绝对词先在本线内自查。**「唯一一次」被同一条线后面的站打了脸。
   写「唯一」「第一」「从未」之前，把全线扫一遍。

4. **「」只留给真引文。**
   全篇的约定是「」＝可核对的史料原文。作者自己的比喻性归纳不许套这个记号
   （赤壁线「有据可查的部分」）；反过来，史料原文必须加（陈寅恪那句漏了）。

5. **落点/序里的清单，每一项都要能指回某一站。**
   「苏轼添了月亮和箫声」——前赤壁赋那一站根本没讲月亮和箫声，讲的是问号。

## 二、结构层

6. **翻转句是盐不是饭。**「不是A，而是B」「问题不在于A，在于B」及其变体
   一条线至多一两处。勘合线初稿里有五处，模板感一读便知。
   修法：改成正面陈述或「A分两种」式的并列。

7. **计数模板别复用。**「这条线上第N个……的地方」出现第二次就成了报数。

8. **插入的旁例要有过桥。**从郑和跳到龙门二十品，中间没有一句话交代
   「例子不在船上」，读者会不知道自己在听哪条线。
   自查法：把这段抽掉，前后若照样连得上，它就是没桥的。

9. **卡片与长文不逐字重复。**长文开头把 b2 又念一遍等于没推进；
   长文该做的是换个说法、加上卡片放不下的东西。

## 三、语言层（机器味与翻译腔）

10. **名词化是头号机器味。**动词被压成名词就改回动词：
    「一个执行的案例都没有」→「一次都没有真用过」；
    「地点的认定」→「认定地点」；「执行回执」→「回执」；
    「推进事实」→「添新事实」。

11. **「取材」「落脚」这类动词不接「是」。**「取材是…那一幕」→「取材于」。

12. **「被」字别孤零零收尾。**「如今大体被接受」→「如今学界大体接受」。

13. **文言凝缩别混进口播。**「以武则天为容貌所本」→「照着武则天的样子雕的」。
    尤其注意「为…所…」是被动式：「为亡故的长辈所造」主宾是反的，
    要说「为纪念亡故的长辈而造」。

14. **修饰语挂对主语。**「他身后跟着一个猴脸的行者，合掌而立」——
    合掌的是玄奘，就近原则会把动作读到猴子身上。朗读一遍就能听出来。

15. **没有对照对象就不加对照限定词。**「中国的记载说」——附近没有别国记载，
    这个「中国的」是翻译腔。

## 三之二、声口层（2026-08-21，用户定）

16. **站题当钩子，不当论点。** 叙事段与站题取纪录片的「场景先行」声口
    （BBC／央视纪录片之最佳者）：题目不剧透论点，论点让正文自己揭。
    「账在，东西没了」（论点先行）→「静治堂的灯」（场景先行）。
    底线是**虚中带实**：题目再抒情也必须指向本站独有的那件事——
    空到能挪去任何一站的题（「时光变化」一类）不用。
    序与落点的题本就是钩子体，不受此改。b/b2 仍是事实位，不跟着虚。
    **补（用户 2026-08-21 定）**：「碑铭式短句」与「场景先行」并列合法——
    「账在，东西没了」自有金石断语的历史感，留任金石录站。禁的只是空题，
    不是某一种声口。

## 流程

- 评审可复用 workflow 脚本 `review-storyline-prose`（三镜头找 → 逐条对抗复核）。
- **改法只许换说法，不许增删史实**；agent 的 rewrite 若带进新史实或改动人名，驳回重拟。
- 改完 `js/line-text-*.js` / `js/lines.js` 后，**必须重跑
  `tools/mining/build_line_page.py <key>` 同步 story-*.html**——那是生成物。

## 流程定序（2026-08-20，用户定）

一条线的工序：**起稿 → 定调定情节（三镜头评审、改稿、重生成页面）→ 配图**。
配图放最后——图是贴着定稿的那句话找的（pick_pics 按叙述原句检索 Commons），
文字还会动就去配图，等于给要拆的墙刷漆。
**例外**：对话里已经点过将的照片（用户拍摄、当场指定「这张配某站/某条」的）
不受此序约束——那不是找图，是已经选完的图，随时接上。

## 十七、同题异文对账（2026-08-21 立，五处漂移实案后）
卡片 b/b2 与长文是**两篇文章**（打光句 vs 解说词），不许合并也不许失联：
- 改 line-text 任何一站，同一 commit 必须复核该站 b/b2 的事实与分级是否还对齐
  （错型一的施工版：查改处，不必重写）；
- 漂移审计（docs/desk/audit-line-drift-*.md 方法）作例行体检，每轮线文大修后跑；
- 同文异地者（题辞/引文这类逐字复用件）不适用本条——那类走唯一源，机器保证。

## 语感篇·十八至二十二（2026-08-22 立，勘合线大修所得；库主验收语「像央视最好的 documentary」）

**十八、站题碑文化。** 站题按碑额写：四至六字为上，文言倾向而不酸腐，摘下来能独立成文。
忌口语指代开头、忌论点句、忌流水账。范式即库主示范：「它没有败给火」→**「未败于火」**。
同批合格件：令下而文同／立石待校／石上易姓／碑称戾公／宫中焚其籍／帐上三字／剖券为二。
（注意辖区：站题 t 只在导览卡与时间轴现身，story 页 h2 用条目名——改题不动条目名。）

**十九、悬空指代是语感头号杀手。** 段首「它」「这个」一律有名有姓化或承上顺接。
实案：「它被记录下来，比它被凿走更早」→「记录它的人，比凿它的人来得早」——
连用被动是翻译腔信号，**改成人做主语**，一箭双雕。

**二十、一线一族动词。** 每条线选定自己的动词族并贯穿全线：勘合线＝合／核／对，
香火线＝发／撕／追认。lede、站文、落点同族呼应；散用近义词等于把线魂稀释。

**二十一、文言收笔胜白话解释。** 段末收束宁取史笔短句（「核人者，亦为人所核」
「器物改正了记录，记录没有跟着改」），不取解释性长句。一句一落，留白胜解释。
另：错型六（翻转句）的复核标准自关林案后明确为**「否定载不载信息」**——
挣得起自己的否定才留，纯为后半句搭台的砍。

**二十二、语感大修的工序（程序条）。** ①**单主笔全线改**——声口要统一，禁逐站分包
（多 agent 拼贴必碎）；②交稿后**三重机械对账**：段数逐站相等、「」引文集合逐站相等、
阿拉伯数字集合逐站相等，任一不合先审后落笔（作者自话摘引号属清单第四条合规项，
人工放行）；③主判抽查史实与分级措辞；④落笔重建生成物。勘合大修 8a7c4fe 即首案。
