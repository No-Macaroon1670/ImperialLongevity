# 故事线解说词：常见错型清单

2026-08-20 对三条线（石窟、赤壁、勘合）做了一轮三镜头评审（AI 腔／纪录片纪律／
生硬拗口），45 条意见复核通过 23 条、全部落地。**此后起新线，写完先对照这张单子
自查一遍**——这些不是风格偏好，每一条都在自己线上真实出过。

## 一、事实层（最重）

1. **短文案与长文的事实级别必须一致。**
   窄屏读者只读得到卡片上的 b/b2，读不到长文里的限定语。长文写「学者推断、
   大体被接受」，卡片就不许写成断言。
   实例：云冈卡片「五尊大像，对应五位先帝」——长文自己写明那是二十世纪学者
   重建的推断。改：「学者推断对应五位先帝」。

2. **接力的事别安在一个人头上。**
   实例：「海通法师发愿开凿，凿了九十年才成」——海通死时佛未成，是三个人接力。

3. **绝对词先在本线内自查。**「唯一一次」被同一条线后面的站打了脸。
   写「唯一」「第一」「从未」之前，把全线扫一遍。

4. **「」只留给真引文。**
   全篇的约定是「」＝可核对的史料原文。作者自己的比喻性归纳不许套这个记号
   （赤壁线「有据可查的部分」）；反过来，史料原文必须加（陈寅恪那句漏了）。

5. **落点/序里的清单，每一项都要能指回某一站。**
   「苏轼添了月亮和箫声」——前赤壁赋那一站根本没讲月亮和箫声，讲的是问号。

## 二、结构层

6. **翻转句是盐不是饭。**「不是A，而是B」「问题不在于A，在于B」及其变体
   一条线至多一两处。勘合线初稿里有五处，模板感一读便知。
   修法：改成正面陈述或「A分两种」式的并列。

7. **计数模板别复用。**「这条线上第N个……的地方」出现第二次就成了报数。

8. **插入的旁例要有过桥。**从郑和跳到龙门二十品，中间没有一句话交代
   「例子不在船上」，读者会不知道自己在听哪条线。
   自查法：把这段抽掉，前后若照样连得上，它就是没桥的。

9. **卡片与长文不逐字重复。**长文开头把 b2 又念一遍等于没推进；
   长文该做的是换个说法、加上卡片放不下的东西。

## 三、语言层（机器味与翻译腔）

10. **名词化是头号机器味。**动词被压成名词就改回动词：
    「一个执行的案例都没有」→「一次都没有真用过」；
    「地点的认定」→「认定地点」；「执行回执」→「回执」；
    「推进事实」→「添新事实」。

11. **「取材」「落脚」这类动词不接「是」。**「取材是…那一幕」→「取材于」。

12. **「被」字别孤零零收尾。**「如今大体被接受」→「如今学界大体接受」。

13. **文言凝缩别混进口播。**「以武则天为容貌所本」→「照着武则天的样子雕的」。
    尤其注意「为…所…」是被动式：「为亡故的长辈所造」主宾是反的，
    要说「为纪念亡故的长辈而造」。

14. **修饰语挂对主语。**「他身后跟着一个猴脸的行者，合掌而立」——
    合掌的是玄奘，就近原则会把动作读到猴子身上。朗读一遍就能听出来。

15. **没有对照对象就不加对照限定词。**「中国的记载说」——附近没有别国记载，
    这个「中国的」是翻译腔。

## 三之二、声口层（2026-08-21，用户定）

16. **站题当钩子，不当论点。** 叙事段与站题取纪录片的「场景先行」声口
    （BBC／央视纪录片之最佳者）：题目不剧透论点，论点让正文自己揭。
    「账在，东西没了」（论点先行）→「静治堂的灯」（场景先行）。
    底线是**虚中带实**：题目再抒情也必须指向本站独有的那件事——
    空到能挪去任何一站的题（「时光变化」一类）不用。
    序与落点的题本就是钩子体，不受此改。b/b2 仍是事实位，不跟着虚。
    **补（用户 2026-08-21 定）**：「碑铭式短句」与「场景先行」并列合法——
    「账在，东西没了」自有金石断语的历史感，留任金石录站。禁的只是空题，
    不是某一种声口。

## 流程

- 评审可复用 workflow 脚本 `review-storyline-prose`（三镜头找 → 逐条对抗复核）。
- **改法只许换说法，不许增删史实**；agent 的 rewrite 若带进新史实或改动人名，驳回重拟。
- 改完 `js/line-text-*.js` / `js/lines.js` 后，**必须重跑
  `tools/mining/build_line_page.py <key>` 同步 story-*.html**——那是生成物。

## 流程定序（2026-08-20，用户定）

一条线的工序：**起稿 → 定调定情节（三镜头评审、改稿、重生成页面）→ 配图**。
配图放最后——图是贴着定稿的那句话找的（pick_pics 按叙述原句检索 Commons），
文字还会动就去配图，等于给要拆的墙刷漆。
**例外**：对话里已经点过将的照片（用户拍摄、当场指定「这张配某站/某条」的）
不受此序约束——那不是找图，是已经选完的图，随时接上。

## 十七、同题异文对账（2026-08-21 立，五处漂移实案后）
卡片 b/b2 与长文是**两篇文章**（打光句 vs 解说词），不许合并也不许失联：
- 改 line-text 任何一站，同一 commit 必须复核该站 b/b2 的事实与分级是否还对齐
  （错型一的施工版：查改处，不必重写）；
- 漂移审计（docs/desk/audit-line-drift-*.md 方法）作例行体检，每轮线文大修后跑；
- 同文异地者（题辞/引文这类逐字复用件）不适用本条——那类走唯一源，机器保证。

## 语感篇·十八至二十二（2026-08-22 立，勘合线大修所得；库主验收语「像央视最好的 documentary」）

**十八、站题碑文化。** 站题按碑额写：四至六字为上，文言倾向而不酸腐，摘下来能独立成文。
忌口语指代开头、忌论点句、忌流水账。范式即库主示范：「它没有败给火」→**「未败于火」**。
同批合格件：令下而文同／立石待校／石上易姓／碑称戾公／宫中焚其籍／帐上三字／剖券为二。
（注意辖区：站题 t 只在导览卡与时间轴现身，story 页 h2 用条目名——改题不动条目名。）

**十九、悬空指代是语感头号杀手。** 段首「它」「这个」一律有名有姓化或承上顺接。
实案：「它被记录下来，比它被凿走更早」→「记录它的人，比凿它的人来得早」——
连用被动是翻译腔信号，**改成人做主语**，一箭双雕。

**二十、一线一族动词。** 每条线选定自己的动词族并贯穿全线：勘合线＝合／核／对，
香火线＝发／撕／追认。lede、站文、落点同族呼应；散用近义词等于把线魂稀释。

**二十一、文言收笔胜白话解释。** 段末收束宁取史笔短句（「核人者，亦为人所核」
「器物改正了记录，记录没有跟着改」），不取解释性长句。一句一落，留白胜解释。
另：错型六（翻转句）的复核标准自关林案后明确为**「否定载不载信息」**——
挣得起自己的否定才留，纯为后半句搭台的砍。

**二十二、语感大修的工序（程序条）。** ①**单主笔全线改**——声口要统一，禁逐站分包
（多 agent 拼贴必碎）；②交稿后**三重机械对账**：段数逐站相等、「」引文集合逐站相等、
阿拉伯数字集合逐站相等，任一不合先审后落笔（作者自话摘引号属清单第四条合规项，
人工放行）；③主判抽查史实与分级措辞；④落笔重建生成物。勘合大修 8a7c4fe 即首案。

**廿三、破壁词禁令（下沉令施行条）。** 库主令（2026-08-31，逐字）：「这些可以留一些但是需要
酌情。必须要符合故事线需求。其他过于累赘的库内细节应该放在简注和考据。」
考据卡词汇与系年器质细节不入正文：锚取／锚打／主锚／轴位／系年也软／库条／刊文层／转述层／
两读／全条／cf·u1·u2 记号／外文缩写与站名代号（ctext 须作「中国哲学书电子化计划」）。
正文只留讲故事的基本解释；术语的正当住处是考据卡。改法两式（批二 b6b9256 全批先例）：
**翻成人话**（「锚打在一本书上」→「年份钉在一本书上」；「演期两读」→「一作五十日、一作十五日」；
「库条自己拒绝认领」→「本库这一条自己拒绝认领」），或**整句下沉考据卡**（轴位句、坐标锚句、
版本比对括注径删下沉）。落库前机扫：正文层残词归零，卡层术语照准保留。

**廿四、主语链不许断。** 一站之内段落接力同一主语，或段首显式交接。汾阴站病即四段四个
起点（「先秦四部书」「国家祀典这一层」「这个名字」「底下那个世界」），读者每段重新找锚。
自查法：把各段头一个实义名词抄成一列，主语换了三次以上而无交接句的站重写。

**廿五、伏笔就地给钩，指代当句有物。** 向前伏笔（「这一层里没有一个字提到女神，也没有一个字
提到墓」——女神与墓此时尚未出场）必须当段给读者一个数这两样的理由，或删。悬空前指同禁：
「这一点从第二站起就得记住」——「这一点」回指的论点不在读者手里，要么当句重述要么删。
横跳出线必带过桥（错型八的站级版）；非本站必需的跨线交代（「那张地契的正事在另一条线上」）
整句下沉考据卡。

**廿六、设问不当粘合剂。** 「可是这两件事，我们是从哪里知道的？」式设问过渡，一线至多一处，
且须是本站论点本身（史源层级站合法）；当转场胶水用即删，改陈述接力。

**廿七、英语用词逻辑（翻译腔子型续，接错型十至十五）。** 批二与病标本再录四型：
①抽象名词坐主语位——「可考最早的记载写作…」无物主语，补具体物（「冰糖葫芦可考最早的一笔」）；
②介词框套——「在…这一层里」「从…的角度」框住整句，拆框直说；
③不及物悬空——「伐匈奴耗竭之际」谁耗竭？补「国用耗竭」；
④词义错位——「回护」当「回驳」用、「同框」（镜头词）当「同在一器」用。
总自查：凡读着像译文的句子，朗读一遍，照说话的顺序重写。

**廿八、复审班制五律（站级结构大修程序条，代亡佚种子册）。** 语感复审以线为单位开班：
①站级结构＋句级语感**双改**（句级外评治不了站级结构，rewrite 级不降格为改词）；
②**事实与引文一字不许动**，带进新史实或改动人名即驳回重拟（承流程节旧规）；
③破壁词照廿三下沉；④本线声口（比喻族、动词族）保留，已落终稿的外评改笔不回退；

## 语感篇四·卅二（2026-09-02 湖州镜「无可勘合」案库主亲裁立）

**卅二、断语否定过强（否定断言军规的定稿断语层）。** 站文的落点断语、加粗站眼也受
「否定断言必挂检索面」辖——**「实据无存」不得写成「事情不存在」**。湖州镜站原落点
「这一站只有记录，无可勘合」被库主终裁删除：拿「真」字到铺子里核真假这种事，
「我们无法确定是否有勘合，却不能确定没有。概率挺高，实据无存」（库主原话）——
断语一锤定音的姿态恰恰把检索面的缺记说成了史实的缺席。改法两式：
①推测层如实写（「想来不难」「或许日日有」——概率高的事可带推测语入文）；
②收束用「不得而知」族（「宋朝是否真有人这样核实过，如今也是不得而知了」）。
自查口令：每个加粗断语过一遍——它断的是「没查到」还是「没有」？是后者，降级或删。
**边界（2026-09-02 郑和「两通碑」案库主校准）**：卅二辖「有具体可想见反例路径」的断语
（湖州镜的核验——拿到铺子一问，形态明确、概率挺高），**不辖纯逻辑上的未知可能**
（「万一还有第三通总账碑佚失无闻」——无任何线索）。以已知存世与著录为底的常态陈述照写，
不必句句设防——库主原话：「也不能总是害怕 universal negative 可能性。」
**总注（同日库主方法论入档）**：错型是判例集，不是法条——库主自道「因事制宜」「很多时候都忌讳硬规则」，
且自认「来回摇摆的人」。摇摆是掂量的过程：湖州镜案三轮（想写核验场景→收「不得而知」→捡回场景、删断语）
即样本，每一轮都比上一轮更准。拿任何错型自查时**逐案掂量优先**，禁机械扫库一刀切；
规则与案情顶牛时，回到案情。

## 语感篇三·廿九至卅一（2026-09-01 勘合线库主终审批立）

> 缘起：库主逐站三问式终审连破七病（寇猛案三问、铁券案两问、天龙山两问、落点两问），
> 病型皆系「字面都不算错、史实核对抓不到」的一类——第一遍、甚至前几遍都过得去，
> 某一遍重读忽然问一句才现形。

**廿九、时序错位。** 句内两个时间点的先后关系没咬紧：
「后人猜了一千年，烧它的人一直这么叫」——叫在猜前，「一直」却像并行延续到千年里
（窑场早废），改「烧它的人早就叫开了」；「越立越多、越立越大」——「大」的趋势不实，
实况是经数递增（七经→十二经→十三经），改「越刻越全」；「九百年后」——口算一遍
（837 到 1660 年代是八百多年）。自查法：凡句里有两个时间词，把先后画出来对一遍。

**卅、嫁接错（最重）。** 甲物的属性安到乙物头上：汉制剖半合验的是**符**，站文写成
「铁券造出来便分作两半」——引文说的与叙述安的不是一物；连站题「剖券为二」都病在题上。
实物还能自证：钱镠券三百余字全文在一件上，若剖半则各剩半文。
自查法：凡写「A 的做法／制度／称号」，回原文核那个做法的**主语**是不是 A。

**卅一、宾语悬空（错型十九姊妹）。** 十九管段首代词，此条管句中名词虚指：
「没有人指得出哪一件」（哪一件什么？）；「还在原地」（原地是哪？——歧义正好读反：
本义流散境外，字面像还在山上）；「出自生产用具」（什么用具？前段点过匣钵，回指又虚掉）。
**自查三问（库主 2026-09-01 实测工序）：指什么、真的吗、先后对吗**——
终审前拿这三问逐站过一遍自己的稿子，比通读挑毛病有效。

〔第 10 条追记 2026-09-01：本条两个改法示例（「一次都没有真用过」「回执」）当日均以
事实层病废——前者系无源否定断言（否定断言必挂检索面，METHODS 判例），后者比喻方向歪
（回执是收方签给发方，墓志不写给朝廷看）。**语言顺不豁免事实层**；名词化仍是病，
但改回动词后还要过卅一的三问。〕

## 流程篇·修缮（2026-09-01 库主令「能修缮就修缮」，主循环补五缺）

**甲、全工序图（一条线的完整生命）。**
prestage（叙事契约四问→素材盘点对库→幕表：站题照十八碑文化、动词族照二十、悬念账本→**库主圈准**）
→ 起稿（单主笔，中文工作流）→ 定调定情节（三镜头评审＋库主逐站过手）→ **终圈**（廿八强制：
逐站过本单＋对标良品三线＋**卅一三问审**：指什么、真的吗、先后对吗）→ 配图（文字定稿后才配，
流程定序旧规）→ 落库（lint→重出生成物→commit 带 pathspec→push）。
prestage 卷体例照 docs/desk/prestage-shenhou-craft.md 先例；prestage 不写解说词。

**乙、正本／生成物分层表（2026-09-01「改错层」实案立，最易踩的坑）。**
正本三件（改这里）：`js/line-text-<key>.js`（长文）／`js/lines.js`（站卡 b/b2 与站题 t）／
`docs/sources-<key>.json`（考据卡）。
生成物三件（**勿手改**，改了会被下次重生成冲掉）：`docs/line-<key>.md`（build_line_doc 出）／
`story/<key>.html`（build_line_page 出）／`js/line-pics.js`（随 page 重出）。
craft 叙事稿（`docs/line-<key>-craft.md` 前段）是**历史底稿**：不随正本同步，头部挂阅前注，
外审勿以它为现文（Gemini 折子误引案）；craft 的追记区是活档。
改正本后必跑：build_line_doc → build_line_page → lint-js → 同 commit 提交正本＋生成物。

**丙、考据卡同步条（十七的考据版）。** 正文改动**事实结论**（非纯语感）时，同 commit 复核
`sources-<key>.json` 对应站的考据块：结论变了卡跟改（寇猛案、铁券符券之辨即先例），
纯换说法不动卡。反向同理：考据卡新证到手（书影、墓志），正文承其结论者同批改。

**丁、craft 追记护笔制（事实工序成文化）。** 库主亲笔句落库当日记 craft 追记并标
「**复审勿回改**」；主循环批红案（采驳记）各附判词入 craft；改稿被库主推翻的，
误判也记档（秘色瓷神句误护案式）——追记是下一轮复审的护栏与账本。

**戊、外审折子批红制（三重过目式，2026-09-01 库主背书成例）。** 外审（Gemini 等）提名
→ 主循环批红（采驳记各有判词，**先核折子引文是否现文**——外审常拿 craft 底稿当现行文）
