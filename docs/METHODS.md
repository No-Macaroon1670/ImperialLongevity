# 方法总目录——本库的策展体系（2026-08-20 立）

条目是产出，方法是资产。散在各处的军规、判例、台账、工作流，此处一索。

**项目定名（agent 任务书用语，2026-08-21 立）**：本库是**中国历史策展库「王朝之河」**
——事件、文物、故事线、地图四层的通史策展平台；「帝王寿命数据库」是创库时的
旧名，现仅存于生存分析一节与仓库路径。给 agent 的任务书自此用新定名，
以免旧名在收录/叙事的边界判断上悄悄压秤（帝王相关性不是判准，收录三问才是）。
（2026-08-21 孪生 A/B 实测：同一民俗候选单、任务书仅头衔之差，判决 10/10 全同——
命名效应在案卷与判准的具体性面前测不出主效应；改名维持为廉价卫生措施。）

## 军规（成文规则）
- **docs/storyline-prose-checklist.md**——故事线文案十六条错型（事实/结构/语言/声口四层，每条都在自己线上真实出过）
- **docs/sourcing-heritage.md**——景点/遗产类出处次序（国保→世遗文本→方志→考古；维基作索引、百度永不引证）
- **docs/geo-model.md**——落点模型：链/诸说/单点、十九个角色字、陪都三规
- **疆域轮廓军规**（正本在 js/territories.js 抬头契约；此处补 2026-08-26 校验层）——
  轮廓由正史/维基**四至文字**推导，每顶点指得回一句引文，绝不描摹任何历史地图（历史疆界的
  「信息」与「表达」几乎同线：可自由摄取的事实即四至记载本身，地图多给的恰是受保护的判断）。
  **校验层三条防火墙**（库主 2026-08-26 核准）：①**先文后图**——文字推导轮廓定稿冻结后，
  参考源方可出场，顺序不可倒；②**报警不代笔**——比对离群唯一反应是回史料（再挖四至/加示警/
  降置信/宁缺删点），绝不把顶点朝参考挪；③**记检不记值**——工作档可记比对结论，永不转录
  参考坐标，公开注里永不写「据某图调整」。分源许可注：OHM(CC0)/Wikidata geoshape(CC-BY)
  比对随意；historical-basemaps(GPL) 看可抽不可；谭图翻书可描摹不可；**CHGIS 整体排除**
  （合同锁，比对亦不留痕）。勘察情报正本：docs/desk/intel-open-geodata-20260826.md。
  另两判准（同日库主定）：**片内互洽三条**（各家有据/邻界两侧互洽/争议带明写）；
  **邻界互洽分两档**（条约盟书明文共引为首选——澶渊界河/绍兴和议淮水大散关/尼布楚线族；
  无明文则互推＋note争议带）；**锚日收并立**（破碎期以锚定日整图画尽当日并立政权，年份酌情挑）。
- **docs/anchor-policy.md**——系年锚法：锚软不等于出局，六法试尽才许踢（u1/u2 窗口、两说并记、cf 三级、换锚、y/y2 跨度、非系年分歧同理）
- **tools/mining/crop.py 档头**——照片管线全规（三级阶梯/翻拍件/一图多产/裁人群优于打码）
- **导览卡主图程序**（2026-08-22 库主定）：站图供入 docs/pics-<线>.json 时，**必挑恰一张打「卡」标**（判准「图即主语」）——build_line_page.py 汇出 js/line-pics.js，lines.js 尾部通用挂载，tour 导览卡自动带图。一站多图只登打标那张；改标重跑即换
- **tools/mining/photo_triage.py**——闸0.5 三层分拣（L1 需求命中必过/L2 择段备胎/L3 不看，零 token 账面切）。2026-08-22 挂号：C1 主力批实证 249 判仅 3 废（废率 1.2%），词表即需求表，改需求先改词表
- **docs/holding/pics-own.md**（本地）——自摄照片账册＋准入规（OWN_PIC 手选、宁缺勿滥；2026-08-21 防爬转本地：账册逐行描述未发表照片属元数据）
- **馆方 CC0 开放图第三通道**（2026-08-25 用户定向：「更灵活运用各 institute/museum 的
  CC0 image」）——自摄、Commons 之外的第三图源，主战场是流散海外条目。四条军规：
  ①授权逐件实测（Met OA/CMA OA/AIC PD/Smithsonian 等各馆政策不一，波士顿 MFA 即非开放——
  以该件页面标志为准，绝不按馆默认）；②一律 vendor 落本地 img/ 防外链腐（走 vendor_pics
  既有模式），CREDITS.md 照 Commons 体例记 馆名+编号+URL+授权；③API 直链优先（Met/CMA/AIC
  皆有开放 API 带图链）；④与自摄分工按件裁：自摄带亲历叙事、CC0 带画质，判官荐、库主点。
  工序（2026-08-25 首批定）：馆方原档落 `img/museum-cc0/stock/`（gitignore，同 own/ 待遇）；
  库主圈中挂卡者出长边 1600px 网版（q90 渐进去元数据，照 crop.py 家规）落 `img/museum-cc0/`
  顶层入库；条卡接线走 `js/pics-museum-cards.js` 手选表（取图序：自摄＞馆方开放图＞维基缩略），

  按需拆前提塌陷、说明牌重读失据、跨批悬案误清三处遗孤）

  「同人取一」不再作否决理由；教材卷琵琶行等十行密度案照此解锁复审，
  多数宜自末席入库、rank.py 信号复核
- 「假低分不是真冷门」（批八 2026-08-21）——w 存简体而维基正题为繁体且无简体
  重定向页时，rank 信号全灭成假地板分；新条 w 先查正题与重定向，宁写繁体正题

  暂存区，出库操作会被无视（2026-08-20 d1e48ea 实案：删了个寂寞）。untrack 场景
  改用「git status 验净暂存区→裸 commit」；WIP 工作档清单见 .gitignore 注释

## 工作流（可复用流水线）
- 侦察（sonnet 广撒网）→ 终审（opus 判断题）→ 落库（单写者）三段式
  **派活显式标模型**（2026-08-26 库主定，用量配平）：workflow 的 agent() 不标模型即继承
  主循环（Fable）——从此一律显式：侦察/扫描/取证=sonnet，终审/总驳官/对抗复核=opus，
  只有对话终裁、单写者落库、要开浏览器的 UI 施工验证留主循环。机械活照旧先问 Python。
- 落库后勤（每批终审落地必做，2026-08-20 欠账 26 个搜不到的新字立此规）：
  重跑 tools/mining/gen_pinyin.py 更新 data-pinyin.js→lint-events 过一遍→再 commit
- verify-line（.claude/workflows/verify-line.js）：claims.py 抽硬断言→分层核验
- 三镜头评审（AI腔/纪录片纪律/生硬拗口→逐条对抗复核）
- 覆盖方法十一套：类层扫描/英文独占/文库典籍/教材正典/引用图谱/照片漏斗/
  5A 名录/日本国宝/庙祀名单/UNESCO/复筛（新尺刷旧案）
- 故事线工序：起稿→定调定情节（双审）→配图最后；story 页与 geo 皆生成物
  **故事线工序分模型档（2026-08-26 库主核准，与「派活显式标模型」同族）**：
  素材提炼/逐站考据侦察=sonnet；事实核验波=sonnet核＋opus裁（62万token教训的出生地）；
  幕表结构稿/解说词起稿/三镜头评审与对抗复核=opus；配图点将机械段与 build 生成物=Python；
  **主循环只握两头**——开工与库主定叙事契约、收工前全文声口终审（十六条错型是底线不是上限）。
- **建成线默认不增改（default on no，2026-08-25 用户定）**——一般不建议往已完成的
  故事线里加东西：新增未必完美，而线是审定过的整体，宁守其完整。精益求精可以，
  但默认答案是「不」：新条与线的关联一律**互见落条目 yc**（零线改动）；真要补站/增改，
  走**独立任务卡候库主点**；成段重写走大修工序（单主笔＋三重机械对账）。
  判例：郭从谦案「不开第十站、不改既有站正文」；演艺线皮影补站任务卡。

## 迁移性
这套体系不依赖中国史素材——判准、台账、双审、覆盖漏斗对任何文明的
类似工程同构可用（用户 2026-08-20 语：「类推现在系统也可以在一些别的文明上运用」）。
