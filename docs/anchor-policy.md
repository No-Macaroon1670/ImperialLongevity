# 系年锚法军规——锚软不等于出局（2026-08-20 立）

**缘起**：侦察/终审多次把「系年不确」直接判成「缓办/不立」，被用户驳回
（2026-08-20 上品无寒门案，用户裁定「六年窗口其实也不出我们的框架」并指出
此前已数次误踢）。特此成文：**「缺失远好过猜错」管的是内容——不编数字、
不硬凑年份；不管收录资格——能如实声明不确定性的条目就是合格条目。**
踢掉能留的，是假阴性的一种，与「负面结论必复核」同族同罪。

## 总纲：收录三问（2026-08-20 用户定纲：「我们注重真实存在人和物，
大致能认定或者能辟谣的事情。不一定完全需要确定什么时候发生。」）

收录与否，按序问三层，**层层分开，不许串问**：

1. **资格问**——它是真实存在的人或物吗？这件事大致能认定、或能辟谣吗？
   （「能辟谣」也是资格：辟谣是正业，本库 fig 判准早有此条。故事假人真者，
   入库的主体是「作为文化事实的故事」，同样真实存在。**假人真祀同理**——
   用户 2026-08-20 定纲：「嫦娥应该无此人。但是她当月神可很多年了。是有人
   真给她做庙的。」受祀者可以查无此人，祀之者必有其人：锚一律挂在人做的事上
   （起庙、封号、入祀典、文本首见），judged 主体是香火不是神。判例：文昌帝君
   （张育层累合成）、门神（神荼郁垒今本山海经无此段，佚文录存）。）
2. **排版问**——它在轴上放哪？此为工具箱六法的辖区：窗口、两说、cf、
   换锚、跨度皆排版手段。**排版难，不构成资格否决。**
3. **内容问**——条文里每句话有出处吗？数字打架并存或都不给。此为既有
   铁律辖区。

三层各有各的关口：资格不够的，排版再漂亮也不收；资格够的，
排版永远有办法。历次误踢，病根都是拿第二问的难度去否第一问的资格。

## 工具箱六法（判「不立」前必须逐一试过；判例皆库内实条，可 grep 验证）

1. **u1/u2 窗口字段**——代表锚年 y 定图上位置，u1/u2 如实给窗口，配 cf。
   判例：杜虎符（y:-330，u1:-336 u2:-324，据「称君不称王」内证断窗）；
   葛稚川移居图（y:1360，u1:1340 u2:1368，yc 原话「只能给窗口而不给确年」）。
   ——刘毅「上品无寒门」疏（278–284）即照此办理。
2. **两说并记、主锚声明**——取一说为主锚，yc 里两说并陈、写明取舍理由。
   判例：武举（主锚 702《新唐书》，681 李仁泰墓志说并记）；曲辕犁（879/880
   两说皆后人所推，yc 自我声明「系年是软锚」）；文昌帝君（张育殉国年
   374/366 两说不裁）。
3. **cf 三级置信声明**——cf:1 先秦传世编年推排层（葵丘会盟、初税亩）；
   cf:2 约数/测年区间/无款推定（小河墓地碳十四、乾陵无字碑）；
   cf:3 传说时代铺入坐标（大禹治水，yc 自注「纯为坐标」）。
4. **换锚**——起源模糊的制度/事物，锚在其生命周期中可系年的节点。
   判例：越绝书（搜索摘要锚换书内自证）；乾陵无字碑（立碑无确载，系祔葬
   前后）；本日侦察例：匠籍锚 1645 废籍、部曲锚 577 放免诏。
5. **y/y2 跨度**——过程本身可为锚，不必硬找单点。
   判例：募兵代府兵（723–749）、小河墓地（叠压五层给区间）。
6. **非系年分歧同理**——出土经过、人选名单等打架时并存或都不给，
   不因此毙条。判例：杜虎符出土两说「不取一舍一」；北周行六官五职
   人选各源不一「不列名单」。

## 程序规

- 侦察/终审要判某候选「锚软缓办/不立」，判词必须写明**六法为何皆不适用**；
  写不出来就不许踢。
- 已按旧习误踢的存案（如等级批缓办之诸色户计、灶户），后续终审按本规重议。
- 本规不放松另一头：窗口和置信声明必须**如实**——窗口宽就写宽，
  推排就说推排，绝不许为了入库把软锚伪装成硬锚。
