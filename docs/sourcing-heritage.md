# 「中国景点在维基上太简略，在百度百科上又被修饰浮夸了太重」）

her 类与山寺塔观一族的取证次序，**高于**一般条目的「维基优先」惯例：

1. **国保单位档案**（国家文物局历批全国重点文物保护单位名单）——官定年代分期
   （「明至清」式保守系年）是最硬的锚；省保名录次之。
2. **世遗申报文本**（whc.unesco.org 的 nomination dossier）——世遗项目首选。
3. **旧方志**（维基文库：各省通志、府县志、《读史方舆纪要》一族）——此类景点的
   轴内一手记载多在方志；wsrc 直链判例现成（考工记/汉书例）。库内方志条目
   （华阳国志、元和郡县图志等）即此文体的谱系。
4. **考古与营造文献**——《文物》《考古》简报、营造学社调查报告；塔寺断代以此为准。
5. **维基＝索引不当权威**：条目薄就薄着，w 只作锚（「维基锚是服务不是门槛」）；
   rank 信号弱属实情，r 值按实算不硬抬。
6. **百度＝永不引证**：b 字段只作门户链接；其内容一字不入出处。
   唯一正当用途：「号称天下第一」类吹法可作**接受史素材**（名声也是史料），
   但必须写成「有此名声」而非「有此事实」。

配套纪律照旧：各源不一致并列或不给；「始建于唐」无一手支撑时写「传创于唐
（方志追记）」；屡毁屡建的写「今构为某年重建」（三级阶梯）。
