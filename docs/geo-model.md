# 落点模型：一条目多个地方，图上只出一个点

一件事往往不只发生在一个地方。苏轼生于眉州、显于黄州、卒于常州；昭陵六骏凿于昭陵、
今分藏西安碑林与宾夕法尼亚大学；苏武从长安出使、在贝加尔湖牧了十九年羊、又回到长安。
把这些压成一个点，丢掉的正是这条目最要紧的那部分；全都画上去，图又会糊成一片。

**故：库里记全，图上只出主点；点选那个点，链才展开；松开，链收回去。**

---

## 一、怎么写

`js/events.js` 的 `p` 字段，一个字符串数组，每项是 `地名:角色` 加两个可选记号：

```js
p: ['寿县:战*']                                     单点
p: ['眉山市:生', '黄冈市:显*', '常州市:卒']            链（按时序）
p: ['赤壁市:说*', '嘉鱼县:说', '武昌区:说']            诸说（并存主张）
p: ['唐昭陵:葬', '西安碑林:现*', '宾夕法尼亚大学博物馆:现']   文物，末一处在图外
p: ['涿鹿县:战*~']                                  低置信（传统比定）
```

| 记号 | 意思 |
|---|---|
| `*` | **主点**。图上只出这一个。每条恰有一个 |
| `~` | **低置信**。今地属传统比定、推定、或只由国别推出。画成半透明 |

**地名写的是地名，不是坐标。** 地名是策展判断（该落出土地还是现藏地，由人定），
坐标是事实——一律拿地名去中文维基抓 P625 主坐标，**不许手打**。这与本库
「选图是策展判断、许可与署名从 Commons 抓」是同一条分界。
地名必须是维基上**带坐标的**条目名，解析不出的生成时直接报错，不许留在数据里。

### 角色表

| 角色 | 用在 | 角色 | 用在 |
|---|---|---|---|
| `生` | 出生地 | `造` | 制作地 |
| `显` | 显赫、成事之地 | `立` | 建立、树立之地 |
| `卒` | 逝世地 | `发` | 出土、发现地 |
| `葬` | 埋葬、原置之地 | `现` | 现藏、现陈之地 |
| `贬` | 贬所 | `址` | 遗址本体所在 |
| `行` | 行迹中途 | `战` | 交战地 |
| `都` | 都城 | `起` | 起事地 |
| `迁` | 迁都之后的都城 | `灾` | 受灾中心 |
| `陪` | 与正都**并存**的陪都/留都/别都 | | |
| `说` | 诸说之一 | `颁` | 颁行地 |

`陪` 三条规矩：陪都要写在它所属正都**之后**（build 校验）；渲染时不进迁都
箭头序列（画成箭头会读成迁都），虚线系回所属正都；「几朝古都」只数正都
（`都`/`迁` 的主点）——西安十三朝还是十七朝之争，争的正是陪都算不算，
本库的数字自定义为「库内建都政权数」，不掺陪都的账。
同地已在链上（明南京留都、清盛京）不重复落点，留都表述进政权小传。

链里出现 `说` 即判为**诸说**（并存的主张，不是先后的行迹）；
否则两个点以上判为**链**（有时序）；一个点判为**单点**。

## 二、主点取哪一个

**这是判断，不是规则能算出来的。** 下表是通例，逐条仍要看记载。

| 类 | 记什么 | 主点取 |
|---|---|---|
| 名人轶事 `fig` | 生 → 显 → 卒（有记载者） | **显**——做成那件事的地方。不是出生地，也不是墓地 |
| 寓言类 `fig` | 有具体地名者用该地；否则国别的都城 | 唯一那个点，且 `~` |
| 文物 `art` | 造/立 → 发 → 现 | **现藏地**。全在图外者取链上最后一个图内点 |
| 战事 `war` | 交战地；诸说并存者全记 | **主说**——学界主流所主的那一说 |
| 遗址·建筑 `her` | 本体 | 本体 |
| 文化·科技 `cul` | 成事之地 | 成事之地 |
| 制度 `gov` | **只在记载明指一地时才记** | 那一地 |
| 民变 `rev` | 起事地 → 主要活动地 | **起事地** |
| 外患·外交 `out` | 中方一侧的落点 | 那一处 |
| 灾疫 `dis` | 受灾中心 | 那一处 |
| 朝代（`js/dynasties.js`） | 都城迁徙链 | **主都**——这个政权最被认作「都在哪儿」的那一处 |

### 制度类为什么大多不落点

**全境施行的诏令没有一个发生地。**「书同文」「推恩令」颁行天下，落在都城
不是「它在那儿发生」，是「诏书从那儿发出去」——两回事，混起来会让读者
以为制度史集中在几座城里。

故只在**记载明指一地**时才落：

- 盘庚迁殷——两处地方写在事件名里
- 官办交子——《宋史》明记行于四川
- 昭勋阁二十四功臣——就在昭勋阁

治世·中兴（文景之治、贞观之治）同理，一般不落。

## 三、图上怎么读

- **默认只出主点。** 一条目一个点，颜色即类别（与时间轴同色），大小即分量。
- **半透明的点是低置信**：今地属传统比定或推定。与本库先秦年代用斜纹表低置信
  是同一个语汇——形状告诉你有这回事，透明度告诉你别拿它当准。
- **点选主点，链展开**：按时序连线，中途各点画小一圈，各自标名与角色。
  诸说则不连线，把候选一起亮出来——读者要看见这地方至今没定论。
- **松开，链收回去**，只剩主点。图不因为读者点过一下就永久变密。
- **图外的点不画在图上**，只进信息栏。硬贴到图框边上会让读者以为它就在那儿。
- **挨得近的点做散开**（packing）：按**视口上的距离**判，不按经纬度——
  北京与十三陵不是同一处，但在全国尺度的图上贴在一起，就该散开画。
- **一处超过八条即收成一个聚合点**，标上条数，点开展成一环。

## 四、以后可能的升级：投影

眼下是**等距圆柱、x 按 35°N 压缩**，不换。中国轮廓看着熟悉，这个熟悉本身
是可读性的一部分；图外线的方向问题已经用大圆方位角单独修掉（`bearing()`），
不值得为几条线动整张图。但两个替代方案记在这里，将来真要动再拿出来：

1. **以中国为中心的方位等距投影**（中心取约 35°N 105°E）。从中心出发的
   方向与距离全部为真——「苏武往北去了」「六骏往东北去了费城」在图上
   直接可读，不必再算。代价：底图重生、经纬网变弯、轮廓会转，
   读者对国图的既有印象断掉。改动量：build_basemap.py 与 project() 各一处，
   加上所有既有落点重投影，约一小时。
2. **另做一张「天下图」切换**。主图不动，另给一个按钮切到全球方位等距图，
   专看流散到国外的那几件（大英、宾大、根津、大都会…）。工作量最大，
   但两张图各守各的题：主图讲「库里的东西在哪儿」，天下图讲「东西离开之后
   去了哪儿」——后者本身就是个叙事题目，将来做「流散线」时顺手一起做。

## 五、英文维基条目（`en:` 前缀）

流散在外的东西常常只有英文条目——ROM 的《弥勒说法图》、宾大的两骏。
**记录在谁手里，条目就在谁的语言里**，这本身就是这类条目要讲的事。
故 `w` 允许 `en:` 前缀（`w: 'en:Paradise of Maitreya'`），约定一次铺满全部消费端：

- **知识卡**：摘要与「维基百科全文」链接走英文维基，按钮明写「（英文）」；
  百度按钮没手写 `b` 就自动藏（英文标题拿去百度必然 404）。
- **坐标管线**：`coords_of` 按前缀分流到 en.wikipedia，四道兜底
  （主坐标→非主坐标→Wikidata P625→全文检索）全部照走；返回键保留前缀原样。
- **`p` 链**：地名照旧优先用中文条目（现藏机构多半有中文条目，如
  皇家安大略博物馆）；确实只有英文条目的地名同样可用 `en:` 前缀。

这与「天下图／流散线」（第四节）是同一个题目的两半：数据先备好，图另说。
